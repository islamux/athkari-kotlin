## ١. المتطلبات البيئية (تُجهَّز قبل المحاضرة)

| المتطلب | القيمة | الدليل/الملاحظة |
|---|---|---|
| محاكٍ أو جهاز فعلي | API 34 (مُستهدَف و مُجمَّع به) | `app/build.gradle.kts:9,14` |
| الحد الأدنى للتشغيل | API 24 `minSdk` | `app/build.gradle.kts:13` |

**قبل بدء المحاضرة (دقيقتان):**

```bash
./gradlew assembleDebug
adb install -r app/build/outputs/apk/debug/app-debug.apk
adb shell pm grant com.athkarix.app android.permission.POST_NOTIFICATIONS   # أجهزة API 33+
adb shell am start -n com.athkarix.app/.MainActivity
```

ملاحظة أداء: افتح التطبيق وأغلقه من الكاش قبل الصعود لضمان إطار أول نظيف.

### سيناريو ٢ — أذكار الصباح: AUTO_ADVANCE حتى الاكتمال (٢:٣٠)

**ماذا أقول:**

**ماذا أعرض (مسار سريع للوصول للاكتمال):**

## ٥. قائمة «قُل» و «لا تَقُل»

### قُل (صياغة إيجابية موثّقة)
- «**Offline-first** — لا شبكة إطلاقاً، لا مكتبات شبكة في `app/build.gradle.kts`»
- «**حقن تبعية يدوي (Manual DI)** — كائن `AppModule` يجعل الرسم البياني للتبعيات مرئياً (AppModule.kt:22-24)»
- «التفضيلات محفوظة عبر SharedPreferences (٦ مفاتيح) وجدولة WorkManager تنجو من إعادة التشغيل»
- «**Repository هو المصدر الوحيد للحقيقة** — `AthkarRepository`»
- «الإطار الأول حتمي: الـ ViewModel يقرأ التفضيلات مرة واحدة ويكشف StateFlow»
- «٥٢ اختبار وحدة في ٨ ملفات» — بالعدد الدقيق، لا بصياغة عامة»
- «المحتوى مولّد من Flutter Dart ويحمل شواذا معلنة مثل تكرار TEXT_26» — نزاهة.

### لا تَقُل
- ✗ «لا حفظ للبيانات في التطبيق» / «No persistence» — الصياغة السلبية تفتح عليها أسئلة؛ قل الصحيح: التفضيلات محفوظة، والعدادات والخط في الذاكرة (سلوك معلن).
- ✗ «اختبرنا كل شيء» — الغطاء ٥٢ اختباراً على ٦ ViewModels + أدوات؛ لا androidTest ولا اختبارات Compose UI ولا خدمات الإشعارات.
- ✗ لا تُدّعِ أن البحث يشمل أسماء الله الحسنى — إنه يستثنيها صراحة.
- ✗ لا تُدّعِ أن التطبيق يطلب إذن الإشعارات تشغيلياً — الإعلان فقط، والمنح اليدوي على أجهزة API 33+.
- ✗ لا تقل «زر اكتمال» أو «اهتزاز عند ٧٥٪» — الآلية الفعلية AUTO_ADVANCE والاهتزاز عند الانتقال/الإنجاز (كل ١٠٠ في التسبيح).
