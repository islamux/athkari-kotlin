# حزمة العرض التقني — Athkarix Android

ملخص الحزمة: عرض تقديمي تقني مدته 60 دقيقة عن تطبيق Athkarix Android (Kotlin + Compose, MVVM, offline-first).

---

## محتويات الحزمة

| الملف | الوصف |
|---|---|
| `slides.html` | العرض التقني — 29 شريحة بتنسيق RTL عربي، ثيم ذهبي داكن، تنقل بلوحة المفاتيح واللمس، لوحة نظرة عامة، ملاحظات المتحدث، أنماط طباعة |
| `demo-script.md` | سيناريو العرض الحي — 10 دقائق + خطة بديلة مضغوطة 4 دقائق |
| `qa-guide.md` | دليل الأسئلة الشائعة — 30 سؤالاً وإجابة بالعربية |
| `README.md` | هذا الملف — تعليمات التشغيل والتحقق |

---

## كيفية التشغيل

افتح `slides.html` في أي متصفح حديث. لا حاجة لخادم محلي.

- يعمل دون اتصال بالإنترنت بعد أول تحميل (الخطوط من Google Fonts تُخزّن مؤقتاً).
- للطباعة/تصدير PDF: اضغط `Ctrl+P` من داخل العرض.

---

## اختصارات لوحة المفاتيح

| المفتاح | الإجراء |
|---|---|
| `N` / `→` | الشريحة التالية |
| `P` / `←` | الشريحة السابقة |
| `O` | لوحة النظرة العامة (Overview) |
| `S` | ملاحظات المتحدث (Speaker Notes) |
| `F` | ملء الشاشة (Fullscreen) |

## ترتيب الاستخدام أثناء العرض

1. **العرض التقني** (`slides.html`) — العرض الكامل (29 شريحة، ~46 دقيقة)
2. **العرض الحي** (`demo-script.md`) — عرض تطبيقي مباشر (~10 دقائق)
3. **الأسئلة الشائعة** (`qa-guide.md`) — جدول الأسئلة والإجابات (~4 دقائق)

## قائمة تحقق للمرة الأولى (60 دقيقة)

- [ ] شغّل العرض الكامل مع توقيت (مؤقت/ساعة) مرة واحدة على الأقل
- [ ] تأكد أن عدد الشرائح يتطابق مع العداد (يظهر `29/29` في الأسفل)
- [ ] شغّل أمر البناء والاختبار التمهيديان:
  ```bash
  ./gradlew assembleDebug
  ./gradlew test
  adb install app/build/outputs/apk/debug/app-debug.apk
  ```
  تأكد من نجاح البناء والاختبار والتثبيت
- [ ] اختبر خطة العرض البديلة المضغوطة (4 دقائق) من `demo-script.md`
- [ ] اختبر التنقل بلوحة المفاتيح (→, ←, N, P, O, S, F)
- [ ] اختبر ملء الشاشة (Fullscreen)
- [ ] اختبر ملاحظات المتحدث (Speaker Notes)
- [ ] اختبر لوحة النظرة العامة (Overview panel)
- [ ] اختبر التفاعل باللمس (على جهاز/محاكي)
- [ ] اختبر الطباعة/تصدير PDF عبر `Ctrl+P`
- [ ] حضّر صور احتياطية للعرض الحي (screenshots) كخطة بديلة

## ملاحظات معروفة

- توجد 4 أخطاء `NewApi` مسبقة في `NotificationService.kt` — خطأ في بناء الكود وليس من هذه الحزمة.
- لا توجد تبعيات إنترنت في التطبيق (offline-first)، لكن خطوط Google Fonts تحتاج اتصال في أول تحميل.
